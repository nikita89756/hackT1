# API для парсинга документов и чат-бота

## Описание

Этот проект представляет собой API для парсинга документов и чат-бота, написанный на языках Go и Python. API позволяет создавать модели из документов, отправлять сообщения и получать ответы от чат-бота.

## Структура проекта

* `backend`: содержит код для API, написанный на Go
* `Parser1`: содержит код для парсинга документов, написанный на Python
* `deployment`: содержит файлы для деплоя проекта

## Функционал

### API

* Создание модели из документа
* Отправка сообщения и получение ответа от чат-бота
* Получение информации о чате
* Получение всех чатов

### Парсер документов

* Парсинг веб-страниц
* Парсинг PDF и DOCX файлов

## Требования

* Go 1.23+
* Python 3.9+
* PostgreSQL 13+
* Docker 20.10+

## Установка

1. Клонировать репозиторий
2. Установить зависимости: `go mod tidy` и `pip install -r requirements.txt`
3. Создать базу данных PostgreSQL и выполнить миграции: `goose -dir deployment/migrations postgres "postgres://postgres:postgres@postgres:5432/testdb" up`
4. Запустить API: `go run backend/cmd/hack/main.go`
5. Запустить парсер документов: `python Parser1/main.py`

## Использование

### API

* Создание модели из документа: `POST /api/createModelFromFile` с файлом в теле запроса
* Отправка сообщения и получение ответа от чат-бота: `POST /api/sendMessage` с сообщением в теле запроса
* Получение информации о чате: `GET /api/getChatInformation` с идентификатором чата в параметрах запроса
* Получение всех чатов: `GET /api/getAllChats`

### Парсер документов

* Парсинг веб-страниц: `python Parser1/main.py <url>`
* Парсинг PDF и DOCX файлов: `python Parser1/main.py <file>`
